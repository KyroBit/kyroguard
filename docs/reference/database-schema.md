# Database schema

`@kyrobit/kyroguard` stores everything in six tables.

| Table | Stores |
| --- | --- |
| [`kyroguard_policies`](#kyroguard_policies) | One row per synced policy. |
| [`kyroguard_policy_groups`](#kyroguard_policy_groups) | One row per group (role). |
| [`kyroguard_policy_group_policies`](#kyroguard_policy_group_policies) | Which policies each group grants. |
| [`kyroguard_user_policy_groups`](#kyroguard_user_policy_groups) | Which user has which group. |
| [`kyroguard_user_policies`](#kyroguard_user_policies) | Direct policy grants to users. |
| [`kyroguard_resource_owners`](#kyroguard_resource_owners) | Who owns which of your app's rows. No foreign keys into your tables. |

The Drizzle schemas ship at `@kyrobit/kyroguard/drizzle/schema/{pg,mysql,sqlite}`. The Prisma models ship as `prismaSchemaSnippet` and are scaffolded to `prisma/kyroguard.prisma`. Mongoose creates matching collections and indexes when `kyroguard sync` runs.

Types below are PostgreSQL. The MySQL, SQLite and MongoDB equivalents ship in the packaged schemas, with the same names and constraints. MongoDB collection names follow the model names instead — [`kyroguardModels()`](/reference/mongoose#kyroguardmodels) lists all six. Two notes if you ever write rows by hand:

- `domain` and `tenant_id` are never null. Store `''` when there is no value.
- On MySQL, key columns are `varchar(191)`. Ids, names, domain and tenant values must fit 191 characters.

## kyroguard_policies

One row per synced policy. `name` includes the domain prefix, for example `admin.reports.view`.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | `text` | Primary key. cuid2, generated by the app. |
| `name` | `text` | Full policy name. |
| `domain` | `text` | Domain it was synced under. Default `''`. |
| `label` | `text` | Human-readable label. |
| `scope_options` | `jsonb` | Allowed scope names. Default `[]`. |
| `depends_on` | `jsonb` | Names of required policies. Default `[]`. |
| `created_at` | `timestamp` | Default `now()`. |
| `updated_at` | `timestamp` | Default `now()`. |

| Constraint | Purpose |
| --- | --- |
| `name` UNIQUE | One row per policy name. |

## kyroguard_policy_groups

One row per group. Groups are roles.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | `text` | Primary key. cuid2, generated by the app. |
| `name` | `text` | Group name, for example `teacher`. |
| `label` | `text` | Human-readable label. |
| `description` | `text` | Optional. |
| `is_system` | `boolean` | Internal. Default `false`. |
| `is_active` | `boolean` | Default `true`. |
| `created_at` | `timestamp` | Default `now()`. |
| `updated_at` | `timestamp` | Default `now()`. |

| Constraint | Purpose |
| --- | --- |
| `name` UNIQUE | One row per group name. |

Set `is_active` to `false` to switch a group off everywhere. Direct grants keep working.

## kyroguard_policy_group_policies

Which policies a group grants, and with what scope.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | `text` | Primary key. cuid2, generated by the app. |
| `policy_group_id` | `text` | References `kyroguard_policy_groups.id`. |
| `policy_id` | `text` | References `kyroguard_policies.id`. |
| `scope` | `text` | Scope name, or null for unrestricted. |
| `created_at` | `timestamp` | Default `now()`. |

| Constraint | Purpose |
| --- | --- |
| `kyroguard_pgp_group_policy_uq` UNIQUE (`policy_group_id`, `policy_id`) | Group grants each policy once. |

## kyroguard_user_policy_groups

Group assignments: which user has which group, in which domain and tenant.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | `text` | Primary key. cuid2, generated by the app. |
| `subject_id` | `text` | Your user's id. No foreign key, users live in your tables. |
| `policy_group_id` | `text` | References `kyroguard_policy_groups.id`. |
| `domain` | `text` | Default `''`. |
| `tenant_id` | `text` | Default `''`. |
| `created_at` | `timestamp` | Default `now()`. |

| Constraint | Purpose |
| --- | --- |
| `kyroguard_upg_tuple_uq` UNIQUE (`subject_id`, `policy_group_id`, `domain`, `tenant_id`) | Stops duplicate assignments. |
| `kyroguard_upg_subject_idx` (`subject_id`) | Fast grant lookups. |

## kyroguard_user_policies

Direct policy grants, with an optional scope.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | `text` | Primary key. cuid2, generated by the app. |
| `subject_id` | `text` | Your user's id. No foreign key. |
| `policy_id` | `text` | References `kyroguard_policies.id`. |
| `domain` | `text` | Default `''`. |
| `tenant_id` | `text` | Default `''`. |
| `scope` | `text` | Scope name, or null for unrestricted. |
| `created_at` | `timestamp` | Default `now()`. |

| Constraint | Purpose |
| --- | --- |
| `kyroguard_up_tuple_uq` UNIQUE (`subject_id`, `policy_id`, `domain`, `tenant_id`) | Stops duplicate grants. |
| `kyroguard_up_subject_idx` (`subject_id`) | Fast grant lookups. |

## kyroguard_resource_owners

Who may touch which of your app's rows. This backs `Scope.owned()`, `Scope.granted()` and `Scope.inTenant()` — for single-row checks and list filters alike. See [Ownership](/guide/ownership).

| Column | Type | Notes |
| --- | --- | --- |
| `id` | `text` | Primary key. cuid2, generated by the app. |
| `resource_type` | `text` | Your resource type, for example `grade`. |
| `resource_id` | `text` | Your row's id. |
| `owner_id` | `text` | The user's id. |
| `relation` | `text` | `'owner'` (created it) or `'granted'` (shared with them). Custom values allowed. NOT NULL, default `'owner'`. |
| `domain` | `text` | Domain at creation time. Informational. Default `''`. |
| `tenant_id` | `text` | Tenant at creation time. Read by `Scope.inTenant()`. Default `''`. |
| `created_at` | `timestamp` | Default `now()`. |

| Constraint | Purpose |
| --- | --- |
| `kyroguard_ro_tuple_uq` UNIQUE (`resource_type`, `resource_id`, `owner_id`, `relation`) | Records each entry once per relation. |
| `kyroguard_ro_resource_idx` (`resource_type`, `resource_id`) | Fast ownership checks. |
| `kyroguard_ro_owner_idx` (`resource_type`, `owner_id`) | Fast list filters — the EXISTS probe. |


## Ids and timestamps

- Primary keys are cuid2 strings. The app generates them, not the database.
- MongoDB uses standard ObjectIds instead.
- On SQLite, timestamps have no database default. Rows inserted outside the library must set them.
- Deleting a policy also deletes its group entries and direct grants, in one transaction.
